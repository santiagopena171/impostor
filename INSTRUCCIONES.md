# Impostor Futbolero - Instrucciones

¡Tu aplicación está lista!

## Cómo ejecutarla

1.  Abre una terminal en la carpeta del proyecto: `c:\Users\Santiago Peña\Desktop\impostor`
2.  Ejecuta el siguiente comando para instalar dependencias (si no se instalaron correctamente):
    ```bash
    npm install
    ```
3.  Inicia la aplicación:
    ```bash
    npm run dev
    ```
4.  Abre el link que aparece en la terminal (usualmente `http://localhost:5173`) en tu navegador.

## Cómo jugar

1.  Ingresa los nombres de tus amigos en la lista (uno por línea).
2.  Elige cuántos impostores quieres (1 o 2).
3.  Haz clic en **"Nueva Ronda"**.
4.  Pasa el dispositivo a cada jugador para que vea su rol (tocando su nombre para revelar/ocultar).
5.  ¡A jugar!
